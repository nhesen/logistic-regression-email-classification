# Logistic Regression Email Classification

Email spam classification project using Logistic Regression and TF-IDF.

## Technologies
- Python
- Pandas
- Scikit-learn
- TF-IDF
- Logistic Regression
- Jupyter Notebook

## Project Workflow
1. Load and clean the email dataset
2. Split data into training and testing sets
3. Convert text into TF-IDF features
4. Train a Logistic Regression model
5. Evaluate the model using accuracy, precision, recall and F1-score
6. Improve the model using cross-validation and threshold tuning
